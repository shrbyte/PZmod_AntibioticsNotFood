# AntibioticsNotFood

![alt text](https://github.com/shrbyte/PZmod_AntibioticsNotFood/blob/main/image.jpg "Preview")

Project Zomboid B41 Mod.<br>
https://steamcommunity.com/sharedfiles/filedetails/?id=2941640718<br>

Antibiotics now work like regular pills with multiple uses instead of food.<br>
Changed item type from **Food** to **Drainable**.

### Compatibility<br>
* Mod overrides item itself without adding new items.<br>
* Mod overrides <code>ISTakePillAction:perform()</code> - only adds event trigger so should be no problems with any other mods.
